# Ruth Jewels — Indian luxury storefront

A static, multi-page Ruth Jewels storefront designed for GitHub Pages.

## Included

- Premium home page, collections, product detail and brand story
- Indian-market categories and INR price display using the ₹ symbol
- Browser-based cart, quantity controls and checkout demonstration
- Account sign-in interface
- Responsive layout, reduced-motion support, staged reveal animation and accessible semantic markup
- Clear fashion-jewellery presentation without precious-metal or custom-piece claims

## Important production note

The cart, account and checkout are visual/browser demonstrations only. They use no payment processor, database, secure authentication or real order storage. Connect a commerce backend/payment provider before accepting live payments or customer credentials.

## Publish to GitHub Pages

In the repository: **Settings → Pages → Build and deployment → Source → Deploy from a branch**, then choose `main` and `/(root)`.

The product images currently load from the original public `clinceraj/ruth-jewels-1` repository. Copy those assets into this repository before making the original repository private or deleting it.
